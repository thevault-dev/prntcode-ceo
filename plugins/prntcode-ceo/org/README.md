# PRNTCODE org

One folder per role. The **Chief of Staff**, **Legal** and **Finance** are live: Legal runs on Anthropic's legal plugin with PRNTCODE's playbook, and Finance keeps the forecast, runs scenarios and reviews how money is used (v2.3). **Operations**, **Marketing** and **Sales** are partly live: each has one skill running from this repo, with the rest of its charter still to build. The others are charters only.
