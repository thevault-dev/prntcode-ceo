# Project archetypes — gap checklists & back-planning offsets

Classify from the project name, `Event` flag, and `Needs Content` flag. Offsets are days **before D-Day** and are starting points — compress proportionally when runway is short (and mark `⚠️ compressed`). "Expected tasks" are workstreams, not exact titles: match loosely against existing task titles (a task "sort the guest list" satisfies "Invites/guest list").

Name signals are examples from this tracker's actual history — extend by analogy, don't treat as exhaustive.

## event (launch events, takeovers, activations)
Signals: `Event = Yeah`; names with "Launch Event", "Takeover", "activation". Examples: PRNTCODE House Launch Event, Cinema Akil Takeover, Al Maisan PRNTCODE takeover.
Minimum lead time: **30 days**.
| Expected workstream | Offset |
|---|---|
| Venue / space confirmed | −30 |
| Run of show / event plan | −21 |
| Invites / guest list out | −15 |
| Content plan + shoot for promo | −14 |
| Product / stock ready for the event | −10 |
| Collateral & signage printed | −7 |
| Staffing / roles on the day | −5 |
| Day-of logistics (setup, AV, delivery) | −2 |

## collection-drop (new product drops, seasonal collections)
Signals: "Collection", "Drop", "RTW", "Abayas", "Scarves", "Capsule", "Edit", "Wildflower", "Jungle", "Tennis". Examples: Wildflower - Winter RTW & Abayas, Jungle Edit - RTW, Coral Abayas, Tennis Collection, Drop 10.
Minimum lead time: **45 days**. D-Day = launch/delivery date.
| Expected workstream | Offset |
|---|---|
| Designs / prints finalised | −45 |
| Sampling approved | −30 |
| Production order placed | −28 |
| Pricing set (CFO pricing workstream) | −21 |
| Shoot (product / campaign) | −14 |
| Shopify listings + collection built | −7 |
| Launch content scheduled | −5 |
| Stock received & QC'd | −4 |

## collab (partner collaborations)
Signals: "x" / "X" between two names, "w/", partner brand names. Examples: WHATNOT x PRNTCODE, PRNTCODE x JARCH, Swell x PRNTCODE, MANEBI X PRNTCODE.
Minimum lead time: **30 days**. D-Day = go-live/announcement.
| Expected workstream | Offset |
|---|---|
| Agreement / terms confirmed with partner | −30 |
| Product or asset scope locked | −25 |
| Production / fulfilment plan | −20 |
| Joint content plan agreed | −14 |
| Announcement content produced | −7 |
| Launch-day coordination with partner | −1 |

## popup-retail (pop-ups, retail placements, wholesale)
Signals: "Pop up", "Pop Up", hotel/store/venue names, "Harvey Nichols", "Container". Examples: TDC London Pop up, M7 Qatar Pop Up, Kulture House Pop up, MIZA Container, 25 hour hotel, Cactus District, **Cover AD** (confirmed by Khaled Sep 2026 — a pop-up event in Abu Dhabi, not a magazine cover shoot).
Note: "AD" in this tracker means Abu Dhabi, not Architectural Digest.
Minimum lead time: **35 days**.
| Expected workstream | Offset |
|---|---|
| Space / terms confirmed | −35 |
| Stock plan & quantities | −25 |
| Production / replenishment ordered | −21 |
| Visual merchandising / fixtures | −14 |
| Shipping & customs (if cross-border) | −12 |
| POS / payments / pricing tickets | −7 |
| Staffing & opening logistics | −3 |

## trip (business trips, trade shows)
Signals: "Trip", city names, "Premier Vision". Examples: Jeddah Trip, Amsterdam Trip, Premier Vision - NYC.
Minimum lead time: **21 days**.
| Expected workstream | Offset |
|---|---|
| Purpose & meeting targets set | −21 |
| Flights & hotel booked | −18 |
| Meetings scheduled | −10 |
| Materials / samples to carry | −5 |
| Follow-up plan | +3 (after) — propose only if user wants post-D-Day tasks |

## generic (fallback)
Use when nothing fits confidently; mark `~` soft. No gap detection beyond universal checks. Distribute undated tasks evenly across the runway.

## Universal checks (every archetype, incl. generic)
- **Never** propose social/content-coverage tasks. `Needs Content` is a flag for the social team's separate page, not a gap in this tracker. See SKILL.md Definitions.
- Project has a D-Day but **zero tasks at all** → question proposal: "D-Day in X days but no tasks — plan it now or push the date?"
- Two projects share a D-Day and both are events → question proposal flagging the collision.
